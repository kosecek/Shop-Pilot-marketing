# Shop Pilot – marketing

Pracovný repozitár marketingových podkladov pre Shop Pilot (denný poradca pre e-shopy).

| Súbor | Obsah |
|---|---|
| `strategia/01-ramec-komunikacie.md` | Základný rámec komunikácie so zákazníkmi: pozicionovanie, cieľová skupina, posolstvá, hooky, cesta k žiadosti o ukážku, námietky, kanály, KPI a plán na 90 dní |
| `strategia/02-sablony-textov.md` | Ukážkové texty: web, cold e-maily, príspevky do skupín, LinkedIn, pozvánka na ukážku, partnerský pitch, otvárače na konferenciu |
| `konkurencia/` | Medzinárodná mapa konkurencie (HTML) a zhrnutie, čo z nej vyplýva pre komunikáciu |

Stav: v1.1, návrh na diskusiu (18. 9. 2026). Rozhodnutia zakladateľa (cena 100 €, Shoptet, SK a CZ, referencia Kifra.sk, ukážka na dátach Kifra.sk, Google Cloud s vlastným tenantom) sú zapracované v oboch dokumentoch.
